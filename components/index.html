components / 组件源码目录

这里是组件片段，不是页面入口

本目录存放 header.html、nav.html、footer.html 三个语义化组件源码。它们是供 build.py 注入到页面里的 HTML 片段，本身不包含 <html>、<head> 骨架，也不引用样式表与脚本。

为什么会出现 404？
从 IDE（例如 HBuilderX 的「运行到浏览器」）单独预览 components/ 里的文件时， 片段中的相对链接 index.html#home 会被解析成 components/index.html#home —— 而这个目录并没有 index.html，于是报 404。 同理，css/style.css 与 js/script.js 在该目录下也加载不到。
打开站点主页 → 查看第二页 about.html

正确的访问地址

请打开站点根目录下的 index.html（注意路径里没有 components/）：

HBuilderX 内置服务器：http://127.0.0.1:8848/组件开发与样式统一_提交包/index.html 自建服务器：http://localhost:8000/index.html 最简方式：直接双击 index.html（纯静态，file:// 下可完整运行）

本目录文件

  • header.html — SiteHeader 组件（品牌区 + @slot:nav）
  • nav.html — MainNav 组件（五项锚点导航 + 汉堡按钮）
  • footer.html — SiteFooter 组件（版权 + 页脚导航）
  • index.html — 本说明页（兜底引导，不属于作业组件）

修改组件后请在站点根目录执行 python build.py，所有页面会自动同步。
