关于本站

本页是「组件复用性」的验证页：没有复制任何一行页头或页脚代码，只引用与首页完全相同的 css/style.css 和 js/script.js。页头、导航、页脚由 build.py 从 components/ 目录统一注入，因此在任意数量的页面上表现一致。

请对比本页与 index.html 的页头、导航与页脚；在浏览器开发者工具（F12）的设备模式下切换 375px 与 1440px，两页的汉堡菜单行为也应完全一致。

执行步骤对照

按任务拆解的四个步骤落地，每步均可在源码中找到对应文件。

  1. 第 1 步｜搭建 HTML 骨架

    components/header.html、nav.html、footer.html 使用 header / nav / footer 语义标签，导航用 ul 列表，无多余 div 嵌套，缩进统一为两个空格。

  2. 第 2 步｜编写共享样式表

    css/style.css 以 * { margin: 0; padding: 0; box-sizing: border-box; } 开头做全局重置，页头与导航用 Flexbox 的 space-between / align-items 对齐，颜色统一由 --primary-color 等 CSS 自定义属性管理。

  3. 第 3 步｜实现响应式与交互

    js/script.js 通过 classList.toggle('is-open') 控制菜单显隐，监听窗口变化与断点切换；点击外部、按 Esc、点击链接均会收起菜单，并同步 aria-expanded。

  4. 第 4 步｜全站联调与测试

    组件由 build.py 注入 index.html 与本页，页头页脚显示一致；已在 375px / 1440px 两种宽度与多个页面下检查布局与控制台。

一致性核对要点

单一数据源

页头、导航、页脚各只有一份源文件。修改组件后运行 python build.py，所有页面同步更新，杜绝逐页手改造成的不一致。

样式与脚本完全独立

页面不含任何 inline style 与内联事件，脚本统一用 defer 引入；新增页面只需复制页面骨架，无需改动 CSS 或 JS。

渐进增强

关闭 JavaScript 时，导航按钮隐藏、菜单以可换行列表完整呈现，正文与全部链接仍可正常访问。
